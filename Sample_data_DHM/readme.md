
# 🔒 DHM Station Data & Academic Ethics Policy

This folder contains the structural schema and sample templates for ground-truth observations sourced from the **Department of Hydrology and Meteorology (DHM), Nepal**.

## 🛡️ Confidentiality & Licensing Notice
* **Restricted Redistribution:** Real ground station observational data from DHM is subject to strict data-sharing agreements and proprietary constraints. To uphold academic ethics and prevent unauthorized data dissemination, full observational series are excluded from public repositories.
* **Provided Template:** The file `dhm_template.csv` contains dummy values structured to match the exact schema required by the pipeline. It is provided strictly to test execution flow and verification without exposing sensitive raw data.
